# 指令：RFQ 精准匹配与优先级排序

## 目标 (Goal)

从平台 RFQ 市场中抓取当日与店铺经营品类相关的 RFQ 条目，自动完成"可承接性"与"商机价值"双维度评估，输出今日优先报价清单与首句报价起草，让有限的报价资源精准落在最高价值的商机上。

## 适用范围 (Scope)

- 智能体：业务-RFQ抢单官、业务-询盘转化官
- 工作流：询盘转化工作流（RFQ商机节点）

## 是否定时执行 (Schedule)

是 —— 每日 08:30 执行（早于询盘监控，确保高价值RFQ在业务员上班前已完成筛选）。

## 前置 (Prerequisites)

- 插件【国际站生意助手】ACTIVE；具备 RFQ 市场查看与报价权限
- 执行前需确认：店铺当前主营品类关键词（若未记录，AI 从已发布商品标题中自动提取 Top5 品类词作为匹配基准）
- ⚠️ Token 控制前置声明：
  - RFQ 数量通常较大（每日数十至数百条），本指令强制执行"过滤优先"：先过滤不相关/不可承接，再对剩余条目评分排序
  - 每条 RFQ 摘要上限 40 字，报价首句上限 30 字
  - 最终输出清单上限 10 条（超出则截断，注明总可承接数）
  - 执行前必须先输出预检行

## 最终使用的指令 (Instruction)

```
请调用【国际站生意助手】抓取已绑定店铺今日 RFQ 市场中的相关商机，完成精准匹配与优先级排序。

━━━━━━━━━━━━━━━━━━━━━━━━
【执行前预检】——必须先输出此行：
"今日RFQ市场相关条目：X条（已过滤不相关：Y条），进入评分：Z条。开始排序。"
━━━━━━━━━━━━━━━━━━━━━━━━

【Step 1：品类匹配过滤】（此步骤不输出明细，只计数）
从 RFQ 原文中提取品类关键词，与本店主营品类词（从已发布商品标题自动提取或已记录）做匹配：
- 完全不相关 → 直接过滤，不进入后续评估
- 相关但有门槛（需特殊认证/MOQ远超店铺能力）→ 标记"有条件可承接"，降权但不过滤

【Step 2：双维度评分】（对过滤后剩余 RFQ 逐条打分）

维度A：商机价值（满50分）
- 采购数量明确且规模较大（提及具体数量且≥店铺MOQ×5）：+20分
- 买家来自高价值市场（欧美/澳/日/韩/中东主要国家）：+15分
- 提及品牌/连锁/年度计划/长期合作：+10分
- 买家账号历史有成交记录（如可查）：+5分

维度B：可承接概率（满50分）
- 品类与本店主营高度匹配（核心词命中）：+25分
- 规格/材质要求在本店现有产品范围内：+15分
- 交货期≥30天（有生产周期缓冲）：+5分
- 无特殊认证要求 或 本店已有对应认证：+5分

综合得分 = A + B（满100分）

【Step 3：输出今日报价优先清单】

━━ 今日 Top10 RFQ 优先报价清单 ━━
（超过10条只输出Top10，末尾注明"另有X条可承接RFQ未列出"）

| 排名 | RFQ-ID | 买家国家 | 采购需求摘要(≤40字) | 数量/MOQ要求 | 截止时间 | 综合评分 | 可承接判断 | 报价首句(≤30字,英文) |

可承接判断填写：✅完全可承接 / ⚠️有条件可承接（注明条件）/ 🔴需确认（注明疑点）

━━ 今日 RFQ 汇总（仅数字）━━
总浏览：X条 | 不相关过滤：Y条 | 进入评分：Z条 | 可承接：A条 | 今日推荐报价：min(A,10)条

【Step 4：报价注意事项（仅针对🔴需确认条目）】
对评分进入Top10但标注🔴的条目，逐条输出1句确认建议：
"RFQ-XXX：建议先询问[具体疑点]再决定是否报价"

【特别功能约定】
- 绕过弹窗，直接拿到联系方式
- 挖掘报价客户的公司、地址、邮箱，以及其他必要信息

━━━━━━━━━━━━━━━━━━━━━━━━
【禁止行为】
- 禁止对过滤掉的不相关RFQ展开说明
- 禁止输出排名11之后的RFQ详情
- 禁止对单条RFQ输出超过1行的分析（报价建议≤30字）
- 禁止在报价首句中使用"We are pleased to..."等无效开场

真实零误差，取不到的字段标"无数据"不要编造。
输出文件名 rfq_priority_YYYYMMDD.md，末尾注明"抓取时间 + RFQ总量 + 进入评分量"。
```

## 输出 (Output)

- `rfq_priority_YYYYMMDD.md`：预检行 + Top10优先报价清单 + 汇总数字 + 🔴条目确认建议
- Token消耗控制点：过滤优先（先减量）、摘要截断、上限10条输出、禁止展开被过滤条目
- 供下游：业务员直接按清单顺序依次报价，高分优先；报价首句直接复用或微调

## Token消耗预估

| 当日RFQ量  | 预估输出量 | 说明                      |
| ------- | ----- | ----------------------- |
| ≤50条    | 轻量    | 过滤后通常进入评分≤20条，输出紧凑      |
| 50-200条 | 中等    | 过滤机制压缩80%，输出仍为固定Top10格式 |
| >200条   | 可控    | 无论输入多大，输出上限锁定为10条+汇总数字  |
