# 指令：导出关键词指数

## 目标 (Goal)

导出当前绑定店铺的入店核心词及其搜索指数、带来曝光/点击、竞争度，区分"已有流量词"与"蓝海机会词"，供关键词研究官构建关键词矩阵，指导 Listing 标题/属性词优化与新品布局。

## 适用范围 (Scope)

- 智能体：运营-关键词研究官、运营-Listing优化官
- 工作流：流量转化提升工作流（关键词节点）

## 是否定时执行 (Schedule)

否 —— 按需执行（Listing优化、商品上新或关键词矩阵重建前触发）。

## 前置 (Prerequisites)

- 插件【国际站生意助手】ACTIVE；具备数据纵横 / 关键词效果查看权限
- 字段降级规则（接口返回不完整时自动执行，无需人工干预）：
  - "搜索指数/热度"不可用 → 用"带来曝光量"代替，表头标注"(代理指标)"
  - "蓝海度"不可用 → 用"点击量/曝光量比"代替，表头标注"(代理指标)"
- ⚠️ Token 控制声明：
  - 关键词总表上限 Top20，超出只计数不展开
  - 分类标签直接合并在总表列中，禁止单独再输出分类段落
  - 蓝海机会词清单上限 5 条，超出只计数
  - 行动建议 ≤ 4 条，每条 ≤ 20 字
  - 禁止对每个关键词做逐词解释

## 最终使用的指令 (Instruction)

```
请调用【国际站生意助手】导出已绑定店铺入店关键词数据（近 30 天）。
数据真实零误差，取不到的字段填"无数据"，不要编造。

━━━━━━━━━━━━━━━━━━━━━━━━
【执行前预检】——必须先输出此行，再执行：
"本次导出：入店关键词共 X 个，展示Top20，统计周期 XXXX~XXXX。开始执行。"
━━━━━━━━━━━━━━━━━━━━━━━━

【一、入店核心词总表】（Top20，按曝光降序，超出只注"另有X个词未列出"）
| 关键词 | 搜索指数/热度 | 带来曝光 | 带来点击 | CTR% | 竞争度/蓝海度 | 已布局 | 分类标签 |

已布局列：是 / 否 / 需人工核查
分类标签列（直接在此列填入，禁止单独输出分类段落）：
- 已有流量词（曝光+点击均>0）
- 高潜未布局词（热度≥中 + 竞争度低/中 + 已布局=否）
- 高竞争红海词（热度高 + 竞争度极高）
- 普通词（不满足以上条件）

【二、蓝海机会词清单】（≤5条，超出只注"另有X条蓝海词"，每条1行）
| 关键词 | 热度 | 竞争度 | 建议布局位置(≤10字) |
布局位置选项：标题前段 / 标题后段 / 属性词 / 长尾词 / RFQ关键词

【三、行动建议】（≤4条，每条≤20字，格式："[问题]→[动作]"）
必须覆盖：CTR最低词优化建议（1条）+ 最优蓝海词布局建议（1条）+ 其余视情况补充

【禁止行为】
- 禁止对每个关键词做逐词解释或分析段落
- 禁止将分类标签单独列为一个段落（必须合并在总表列中）
- 蓝海清单超5条只计数，禁止强行列出全部
- 禁止输出"综上所述"等总结句

输出文件名 keywords_index_YYYYMMDD.md，最后一行：统计周期 XXXX~XXXX，抓取时间 YYYY-MM-DD HH:MM。
```

## 输出 (Output)

- `keywords_index_YYYYMMDD.md`：预检行 + 核心词总表（≤20行，含分类列）+ 蓝海词清单（≤5行）+ 行动建议（≤4条）
- Token控制点：总表上限20、分类标签合并入表列、蓝海词上限5、行动建议上限4条+字数截断
- 供下游：关键词研究官构建词矩阵、Listing官嵌入标题与属性、RFQ官匹配商机词
