# 指令：监控询盘与商机

## 目标 (Goal)

每日定时抓取新进询盘、商机(AB) 与 RFQ，结构化输出并完成初步质量分级，第一时间锁定高价值线索，驱动询盘转化官优先响应与大客户开发官定向跟进。

## 适用范围 (Scope)

- 智能体：业务-询盘转化官、业务-大客户开发官
- 工作流：询盘转化工作流（起点数据节点）

## 是否定时执行 (Schedule)

是 —— 每日 09:00 与 15:00 各执行一次，覆盖两个高峰接单时段。

## 前置 (Prerequisites)

- 插件【国际站生意助手】ACTIVE；具备询盘 / 商机(AB) / RFQ 后台查看权限
- IM 数据存在约 30 分钟同步延迟，时间戳以平台记录为准
- ⚠️ Token 控制声明（本指令是6条中Token风险最高的，每日执行两次，须严格控量）：
  - 执行前必须输出预检行，明确本次询盘总量
  - 询盘明细表：🔴高价值条目全量列出；🟡常规条目总量≤20条（超出只计数）；⚪低优先级只计数不展开
  - 摘要字段严格≤40字（原指令80字过长，减半）
  - 跟进提示：只列🔴条目的首句话术，🟡🟡⚪不生成话术
  - 禁止对🟡和⚪条目做任何逐条分析

## 最终使用的指令 (Instruction)

```
请调用【国际站生意助手】抓取已绑定店铺最近 24 小时内的新询盘、商机(AB)与 RFQ。
数据真实零误差，取不到的字段填"无数据"，不要编造。

━━━━━━━━━━━━━━━━━━━━━━━━
【执行前预检】——必须先输出此行，再执行：
"本次抓取：询盘 X 条 / AB商机 X 条 / RFQ X 条，合计 X 条。
其中预判🔴高价值：X条，🟡常规：X条，⚪低优先级：X条。开始输出。"
━━━━━━━━━━━━━━━━━━━━━━━━

【优先级打标规则】（先打标，再按优先级分段输出）
🔴 高价值-立即跟进（命中任意1条即打标）：
- 买家来自高购买力市场（欧美/澳洲/日韩/中东主要国家）
- 出现批量采购信号词：bulk / wholesale / annual order / large quantity / distributor / OEM / ODM / brand
- 提及具体规格 + 明确数量
- 买家公司名可识别为品牌商/连锁/贸易商

🟡 常规-正常回复：仅询价/问样品/问运费，无批量信号

⚪ 低优先级-留观：内容极少（单字/无实质）或历史多次询价未转化

━━━━━━━━━━━━━━━━━━━━━━━━
【一、🔴 高价值询盘明细】（全量列出，每条1行）
| 询盘ID | 类型 | 买家国家 | 公司名 | 摘要(≤40字) | 产品/品类 | 数量/MOQ | 来源 | 收到时间 |

【二、🟡 常规询盘明细】（最多列20条，超出只在汇总中计数）
同上格式，摘要≤40字

【三、⚪ 低优先级】（只计数，不展开）
"低优先级共 X 条，不展开详情。"

━━━━━━━━━━━━━━━━━━━━━━━━
【四、今日汇总】（只输数字，2行以内）
总量：询盘X / AB商机X / RFQX | 🔴X条 / 🟡X条 / ⚪X条 | 待回复（>1小时未回）：X条 | 平均响应时长：X小时

【五、跟进提示】（仅针对🔴条目，每条1行）
格式："[询盘ID] → [英文首句≤20字]"
- 若待回复数>3，首行加：⚠️ 当前X条超时未回复，建议立即处理

【禁止行为】
- 禁止对🟡和⚪条目生成话术或逐条分析
- 🟡超20条只计数，禁止强行列出全部
- 摘要超40字禁止输出（截断后加"…"）
- 禁止在汇总后输出任何总结段落

输出文件名 inquiries_YYYYMMDD_HHMM.md，最后一行：抓取时间 YYYY-MM-DD HH:MM。
```

## 输出 (Output)

- `inquiries_YYYYMMDD_HHMM.md`：预检行 + 🔴全量明细 + 🟡≤20条明细 + ⚪只计数 + 数字汇总 + 🔴首句话术
- Token控制点：三级分段输出、摘要40字截断、🟡上限20条、⚪只计数、话术只生成🔴
- 供下游：询盘转化官 BANT 评分与优先回复、大客户开发官捕获 KA 线索
