# 指令：抓取TOP引流款

## 目标 (Goal)

抓取近 90 天按搜索曝光排序的 TOP 商品榜，输出点击率诊断与分层标签，精准定位"高曝光低点击"待优化款、"有流量无商机"转化漏斗断裂款，以及可复制成功要素的爆品/优品，驱动 Listing 与主图优化的优先级排序。

## 适用范围 (Scope)

- 智能体：运营-Listing优化官、设计-主图详情设计官、情报-选品洞察官
- 工作流：流量转化提升工作流（起点数据节点）

## 是否定时执行 (Schedule)

是 —— 每月 1 日 09:30 执行，输出上一自然月 TOP 商品榜（早于大盘数据，为优化排期提供依据）。

## 前置 (Prerequisites)

- 插件【国际站生意助手】ACTIVE；具备数据参谋商品效果(data-advisor-shop-product)查看权限
- 数据参谋存在 T-2 延迟，商品数据统计截止执行日前 2 天
- ⚠️ Token 控制声明：
  - TOP20 数据表固定20行，每行字段已限宽，禁止在表外逐行解释
  - 诊断标签直接合并在表格列中，禁止单独输出诊断段落
  - 优化优先级 Top5 每条≤25字，禁止展开
  - 成功要素提炼：每个维度≤2句，合计≤6句，禁止逐款展开分析

## 最终使用的指令 (Instruction)

```
请调用【国际站生意助手】抓取已绑定店铺近 90 天 TOP20 引流款（按搜索曝光降序）。
数据真实零误差，注明 statDate，取不到的字段填"无数据"，不要编造。

━━━━━━━━━━━━━━━━━━━━━━━━
【执行前预检】——必须先输出此行，再执行：
"本次抓取：在售商品共 X 个，TOP20 覆盖率 X%，全店搜索CTR均值 X%，statDate：XXXX~XXXX。开始执行。"
━━━━━━━━━━━━━━━━━━━━━━━━

【一、TOP20 引流款数据表】（固定20行，每行含诊断标签列，禁止在表外对任何款做文字说明）
| 排名 | 商品ID | 标题(前20字) | 搜索曝光 | CTR% | FOB价 | 30天商机数 | 分层 | 诊断标签 |

分层判定（填入分层列）：
爆品 = 曝光Top25% + CTR>全店均值 + 商机>0
优品 = 曝光中上 + CTR正常 + 商机>0
潜力品 = CTR>全店均值 但曝光排名后半段
待优化品 = 高曝光 但CTR或商机极低/0

诊断标签（填入诊断列，每款只填1个，按优先级选最严重的）：
🔴主图/标题待优化 = 曝光前10名 但CTR < 全店CTR均值×0.8
🟠详情/定价待优化 = CTR正常 但30天商机=0
🟡加曝光潜力释放 = CTR>均值 但曝光排名11-20
🟢成功要素可复制 = 爆品/优品
（同时满足多条取最高优先级：🔴>🟠>🟡>🟢）

【二、优化优先级 Top5】（≤5条，每条≤25字，格式："[排名][商品ID]：[最高优先动作]"）
按"曝光体量×CTR差距"综合排序，只列动作，禁止展开原因分析。

【三、成功要素提炼】（仅针对🟢款，每个维度≤2句，合计≤6句）
- 标题规律：[≤2句]
- 视觉规律：[≤2句]
- 价格规律：[≤2句]
若🟢款数量=0：输出"本月暂无爆品/优品，跳过提炼。"，结束此节。

【禁止行为】
- 禁止在TOP20表格外对任何单款做逐行文字说明
- 禁止将诊断标签单独列为段落（必须在表格列中）
- 优先级Top5超5条禁止强行列出
- 成功要素每维度超2句禁止展开
- 禁止输出"综上所述"等总结句

输出文件名 top_products_YYYYMM.md，最后一行：statDate XXXX~XXXX，抓取时间 YYYY-MM-DD HH:MM。
```

## 输出 (Output)

- `top_products_YYYYMM.md`：预检行（含全店CTR均值）+ TOP20表（固定20行，含分层+诊断列）+ 优先级Top5（≤5条）+ 成功要素（≤6句）
- Token控制点：固定20行表格、诊断标签合并入列、优先级5条上限+字数截断、成功要素6句上限
- 供下游：Listing优化官按优先级排队处理、设计官按🔴🟠方向出图、选品官参考🟢要素开发新品
