# 指令：导出店铺大盘数据

## 目标 (Goal)

从已绑定的国际站后台抓取核心经营 KPI、转化漏斗、询盘来源分布及同行对比，输出标准化大盘报告，作为每周经营复盘与体系诊断的数据底座。

## 适用范围 (Scope)

- 智能体：管理-经营复盘官、运营-Listing优化官、所有需经营基线的智能体
- 工作流：流量转化提升工作流（效果回收节点）、付费流量激活工作流

## 是否定时执行 (Schedule)

是 —— 每周一 08:00 自动执行，生成上一自然周大盘快照（早于广告诊断，作为基线先行输出）。

## 前置 (Prerequisites)

- 已安装并启用【国际站生意助手】插件，店铺后台授权状态 ACTIVE
- 主账号具备数据参谋 / 数据纵横查看权限
- ⚠️ 数据参谋存在 T-2 延迟，最新有效统计日为执行日前 2 天
- 同行均值/优秀值若接口未返回，填"—"，不编造
- ⚠️ Token 控制声明：
  - KPI 表固定行数，禁止在表外逐行解释数字
  - 漏斗每个环节诊断 ≤ 15 字，仅对低于同行均值的环节输出，正常环节只填数值不输出诊断
  - 行动项 ≤ 5 条，每条 ≤ 25 字
  - 禁止输出任何总结段落

## 最终使用的指令 (Instruction)

```
请调用【国际站生意助手】从已绑定的国际站后台抓取近 30 天经营大盘数据。
数据真实零误差，取不到的字段填"无数据"，不要编造。

━━━━━━━━━━━━━━━━━━━━━━━━
【执行前预检】——必须先输出此行，再执行：
"本次抓取：统计周期 XXXX~XXXX（T-2截止），同行基准 [可用/不可用]。开始执行。"
━━━━━━━━━━━━━━━━━━━━━━━━

【一、核心 KPI 表】（固定11行，每行1个指标，禁止在表外补充任何文字）
| 指标 | 本店数值 | 同行均值 | 优秀基准 | 差距% | 状态 |
状态列规则：低于同行均值20%以上填"⚠️"，其余填"—"
指标行：总曝光 / 总点击 / 搜索点击率seCTR / 访客UV / 商机量AB数 / 询盘数 / 成交买家数 / 成交订单数 / 成交额USD / 平均首次回复时长 / 首次回复率

【二、转化漏斗】（6个环节，每环节1行）
| 环节 | 数值 | 转化率% | 同行均值% | 诊断(≤15字，仅⚠️环节填写，其余空) |
环节：曝光→点击 / 点击→UV / UV→商机 / 商机→询盘 / 询盘→成交 / UV→支付

【三、询盘来源分布】（5行固定，只输出表格）
| 来源 | 询盘量 | 占比% |
行：自然搜索 / 全站推广 / P4P直通车 / RFQ / 其他

【四、行动项】（≤5条，仅针对⚠️环节，每条≤25字）
格式："[环节名]：[具体动作]"
例："seCTR：对TOP5曝光款更换主图，做A/B测试"
- 若无⚠️环节：输出"本周各环节表现正常，维持现状"，结束

【禁止行为】
- 禁止在KPI表或漏斗表外对任何数字做文字解释
- 禁止对状态为"—"的正常环节输出诊断文字
- 禁止超过5条行动项
- 禁止输出"综上所述""总体表现""值得关注"等无信息量文字

输出文件名 shop_dashboard_YYYYMMDD.md，最后一行：统计周期 XXXX~XXXX（T-2），抓取时间 YYYY-MM-DD HH:MM。
```

## 输出 (Output)

- `shop_dashboard_YYYYMMDD.md`：预检行 + KPI表（11行）+ 漏斗表（6行）+ 来源分布（5行）+ 行动项（≤5条）
- Token控制点：固定行数表格、仅⚠️环节输出诊断、行动项5条上限、禁止解释与总结
- 供下游：经营复盘官生成周报、运营官判断优化优先级、广告官判断加投/收缩方向
